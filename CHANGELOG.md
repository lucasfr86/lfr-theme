## [Unreleased]

### Added

- Created the initial LFR Store Framework theme from a minimal boilerplate.
- Added a responsive sticky header with separate desktop and mobile layouts.
- Added the store logo, search bar, login, and minicart to the header.
- Added multi-level desktop category menus and a mobile navigation drawer.
- Added responsive product listing pages for search, brand, department, category, and subcategory routes.
- Added PLP breadcrumbs, titles, filters, sorting, product counts, show-more pagination, and empty-result handling.
- Added responsive product cards with images, names, prices, installment information, and add-to-cart actions.
- Added a responsive product detail page with images, prices, SKU selection, quantity selection, gifts, assembly options, availability handling, and add-to-cart support.
- Integrated the `lfr-custom-installment` block into product cards and the product detail page.
- Integrated the `lfr-shipping-simulator` block into a product detail page modal.
- Added Lato font assets and component-specific Store Framework styles for desktop and mobile layouts.
